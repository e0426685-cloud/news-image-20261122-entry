A 1024x1024 broadsheet front page, "The World Today — 22 November 2026", summing up Sunday 22 November 2026's world news in one image: the Gulf war widening as Iran hits the U.S. air base in Kuwait, COP31 deadlocked over fossil fuels, Russia's 400-drone, 110-missile attack on Ukraine, a magnitude 6.9 earthquake in Peru's Andes, the arrest of cartel boss "El Chapo Isidro", and the Trump–Xi–Putin summit in Shenzhen.

## Run it

```sh
python3 main.py
```

`main.py` (standard library only) copies the prebuilt `entry.png` to the output directory and validates it is a 1024x1024 PNG. The image itself is drawn by `tools/build_image.py` (requires Pillow, build time only).
